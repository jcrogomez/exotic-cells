# `xc19_bias`: bias cell for XC-19

A chain of diode-connected `nfet_01v8` from VDD to GND. The bottom element is 16 transistors drawn exactly like the device under
test of [`xc19_read`](../xc19_read/README.md), one diffusion island each, so they carry the same layout-dependent stress.
Above them, three 1/1 um devices in series: VDD, C1, C2, VB. Tying C1 to VDD gives three in series; leaving it gives four.
About 19.2 x 4.1 um. Generated by `xc19_bias.tcl`.

| Check | Result |
|---|---|
| Magic DRC, full rule set, whole cell | 0 violations |
| KLayout `sky130A_mr.drc` | 0 violations |
| Extraction | 16 mirror devices with gate and drain on VB, three chain devices in series: the intended circuit |
| Residual | all 16 mirror devices get `sa = sb = 0.30`, equal to the device under test |

`channel.sp` simulates this cell with the readout cell, both extracted with parasitics and annotated:

| | Bias | Discharge time | Step for 0.305 mV |
|---|---|---|---|
| Four in series, no added capacitor | 0.323 V | 47.0 us | 0.83 % |
| Three in series, 133 fF added | 0.480 V | 29.2 us | 0.80 % |

Model only. The filter capacitor on VB (10 pF in the simulations) is not drawn.
