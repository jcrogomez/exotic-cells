# `xc19_channel_caps`: the XC-19 channel with its capacitors drawn

[`xc19_channel`](../xc19_channel/README.md) (bias, device A, twin B), flattened, plus:

- **Node capacitors**: one `nfet_01v8` of 4.30 x 4.00 um on each discharge node (gate on X; source, drain and body on GND).
  B is the mirror image of A about the axis between the two X lines.
- **Bias filter**: 33 `nfet_01v8` fingers of 5.5 x 10 um (11 rows of 3) with the gate on VB, 1815 um2 of gate. The fingers are
  5.5 um wide because the full KLayout deck flags (licon.12) any gated diffusion wider than 5.7 um in both directions.
- **Calibration coupling capacitor** on each node: a metal-2 plate of X over a metal-1 plate of CALA / CALB.
- A grounded metal-2 shield between the two X lines.

Ports: VDD, GND, C1, PREA, PREB, XA, XB, VB, CALA, CALB. X leaves each readout cell on metal 2. 34.5 x 94.0 um, 3244 um2.
Generated by `xc19_channel_caps.tcl` (the sizes are parameters at the top).

| Check | Result |
|---|---|
| Magic DRC, full rule set, whole cell | 0 violations |
| KLayout `sky130A_mr.drc`, FEOL + BEOL + off-grid | 0 violations |
| KLayout full deck (`sky130A.lydrc`) with front-end checks switched on | 0 violations (after narrowing the filter fingers to 5.5 um) |
| Extraction | 58 devices: the 23 of the channel, 2 node capacitors, 33 filter fingers. Netlist inspected, no LVS run |
| Residual | the 23 active devices annotated as in `xc19_channel` (18 minimum nfets at `sa = sb = 0.30`); the 35 capacitors stay unannotated, see `annotate.py` |
| Extracted couplings on X | Cc to its CAL line 0.595 fF (A) and 0.607 fF (B); XA to XB 0.023 fF (0.21 fF before the shield) |
| Filter, extracted, AC at VB = 0.480 V | 10.17 pF; chain output resistance 656 kOhm |

Simulation (extracted and annotated, three in series, tt, 27 C): 29.96 us against 29.30 us for the ideal 133 fF; A and B agree
to 0.055 %; the step for 0.305 mV is 0.801 %, the same as with the ideal capacitor. Details, predictions and the calibration
study: [`experiments/xc19_caps`](../../experiments/xc19_caps/INFORME.md).

## Reproduce

```
SKY130A=<path to sky130A> ./run_magic.sh     # draw, Magic DRC, extract
SKY130A=<path to sky130A> ./run_klayout.sh   # both KLayout decks
python3 annotate.py                          # Residual on the active devices
```

## What this is not

Not a macro. Missing: the switched reference capacitor (the calibration that survived; not drawn), pins on a routing grid, an
abstract (LEF), the supply connection, the inverter and counter, the wire from X to the inverter, a formal LVS.
Gate leakage of the capacitors is not in the model (`igcmod = igbmod = 0`).
