# ideas/ — lo que aún no tiene contrato de falsabilidad

Una idea entra aquí con una línea: qué sería, qué observable tendría y qué la mataría. Pasa a `docs/preregistros/` cuando tenga
hipótesis, control negativo, umbral y falsación escritos. No se le asigna área ni RTL antes.

- 2026-11-04 · Vernier de TDC con celdas de retardo de la biblioteca (banco X). Observable: resolución en ps frente a un retardo conocido.
  Lo mata: desapareamiento entre celdas mayor que el paso del vernier.
- 2026-11-04 · Identidad del dado por pares de anillos (PUF). Observable: bits estables entre lecturas y distintos entre chips. Lo mata:
  no tener más de un chip.
