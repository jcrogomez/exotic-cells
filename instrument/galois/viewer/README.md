# Galois viewer: sources

`../galois.html` is one self-contained page (no external requests) that walks through the MISFIT-04 tile as built and the checks
run on it. It is built from the files here.

| File | What it does |
|---|---|
| `extract.py` | Reads the tile's GDS (healthy and each sabotaged one), the core's DEF and the experiments' result files, and writes `data.json`. Every number on the page comes from here. It lists each file it read, with its SHA-256, and the page shows that list on its last step. |
| `gds.py` | A minimal GDSII reader with no dependencies. |
| `page.html` | The page, without its data. Prose and drawing code; no numbers. |
| `build.py` | Inlines `data.json` (gzipped) into the page and writes `../galois.html`. |

```sh
../../../../.venv/bin/python extract.py && python3 build.py
```

`data.json` is not tracked: it is regenerated by `extract.py`. The core's DEF comes from `local_flow/`, outside this repository.

The form of the page (one screen, steps along the top, the layout at true scale with whatever is not the step's subject greyed
out) is modelled on the [Tiny Breakout physical design tutorial](https://github.com/zvea/tiny-breakout) by Alexei Zverovitch.
No code is shared with it.
